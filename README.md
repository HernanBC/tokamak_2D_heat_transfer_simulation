
# Modelo térmico de tokamak tipo ITER

Simulación térmica transitoria 2D axisimétrica del plasma, la primera pared y el divertor.

## Documentación

[Formulación matemática del modelo](modelo%20y%20fundamentos.md)

## Archivos

- `datos/`: perfiles magnéticos, densidad, malla y geometrías.
- `figuras/`: esquemas utilizados en la documentación.

El documento incluye las ecuaciones en forma fuerte y débil, condiciones iniciales y de frontera, propiedades, correlaciones y referencias bibliográficas.
